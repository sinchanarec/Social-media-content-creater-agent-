# Social Media Content Creator Agent

An AI-powered Social Media Content Creator Agent that generates engaging content for platforms such as Instagram, LinkedIn, Facebook, and X (Twitter).

## Features

- Generate social media posts from a topic
- Create platform-specific content
- Generate hashtags automatically
- Create captions and call-to-actions
- Easy-to-use interface
- AI-powered content generation

## Technologies Used

- Python
- OpenAI API
- Streamlit (Optional)
- Git & GitHub

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/social-media-content-creator-agent.git
```

2. Navigate to the project folder:

```bash
cd social-media-content-creator-agent
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Add your OpenAI API key:

```python
OPENAI_API_KEY=your_api_key
```

## Usage

Run the application:

```bash
python app.py
```

Enter:
- Topic
- Platform Name

The AI agent will generate:
- Caption
- Social Media Post
- Hashtags
- Call-to-Action

## Example

Input:

```
Topic: Artificial Intelligence
Platform: LinkedIn
```

Output:

```
🚀 Artificial Intelligence is transforming industries worldwide.

AI helps businesses improve efficiency, automate repetitive tasks, and make smarter decisions.

What are your thoughts on AI adoption?

#AI #MachineLearning #Innovation #Technology
```
